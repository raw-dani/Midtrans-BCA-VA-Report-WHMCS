# Midtrans BCA VA Report for WHMCS

A WHMCS addon module that provides BCA VA settlement reporting functionality with dashboard widget integration.

## Features
- Daily settlement report dashboard widget
- Detailed transaction history
- BCA VA specific filtering
- Amount summaries and transaction details
- Easy to use interface

## Installation
1. Download the latest release
2. Upload the `midtrans_report` folder to your WHMCS installation's `modules/addons/` directory
3. Activate the module in WHMCS Admin > Setup > Addon Modules

## Configuration
1. Configure recipient email for daily reports
2. Set up dashboard widget preferences
3. Access reports via Admin > Addons > Midtrans Settlement Report

## Requirements
- WHMCS 7.0 or later
- PHP 7.2 or later
- Midtrans payment gateway integration
